# Ayush V Nair Projects

Python projects and experiments.

## Projects

- [ClearPrompt](ClearPrompt/README.md) — a local-first Python app that scans text for sensitive data before it is pasted into an AI tool. It includes a native Windows desktop app, an optional Flask web interface, policy controls, and a metadata-only audit log.

ClearPrompt is an educational prototype. It scans content entered into the app and does not monitor other AI applications or provide production-grade security.
